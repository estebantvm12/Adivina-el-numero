# 🎯 Juego de Adivinar el Número - PSeInt
Este es un juego simple desarrollado en [PSeInt] donde el usuario debe adivinar un número secreto generado aleatoriamente entre 1 y 100.

## 🧩 Descripción
El programa selecciona un número al azar entre 1 y 100. Luego, el jugador intenta adivinarlo. Después de cada intento, el programa informa si el número secreto es mayor o menor. El juego termina cuando el jugador acierta.
